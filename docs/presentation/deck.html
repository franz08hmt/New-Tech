    CONTINUITY / PRIVATE HISTORY

    Come back to the
    same conversation.

    1. Save completed, verified turns

      Canonical content and receipt checks; cancelled partial output is not a verified answer.

    2. Open without calling AI

      Personal owner/workspace scope. A manager cannot read another user’s history.

    3. Continue only in the valid scope

      Up to six verified turns. Safe open retry is GET; delete and expiry prevent resurrection.

    A new conversation starts a new thread. It does not delete the saved one.

    Ghi chú trình bày

    TÀI · F07.1 hiển thị lỗi mở rõ, retry chỉ GET. F07.2 initial/retry dùng chung việc đồng bộ document selection; khóa document actions lúc open pending/error. Khác course thật vẫn chỉ đọc. Receipt không phải kho hội thoại. Retention server 90 ngày từ tạo, GET không gia hạn.

    INTERACTION / THẮNG’S TECHNICAL FOCUS

    Control the response.
    Keep the final say.

    [[icon:Signal]]

    Streaming over SSE

    General chat appears progressively.
    Stop aborts and rejects late output.

    Documents publish the answer only after source validation.
    [[icon:Microphone]]

    Local Whisper STT

    Record → inspect → transcribe → edit → insert.
    The user chooses when to send.

    60 s audio · 120 s inference · 150 s API · 180 s outer wait.

    Ghi chú trình bày

    THẮNG · SSE dùng fetch POST/ReadableStream, xử lý UTF-8/frame chia, backpressure/cancel; nginx không buffering. Stop không bảo đảm chưa tính phí upstream. STT MediaRecorder → API → ffprobe/FFmpeg → mono16kHz → Whisper small ONNX CPU/q8. Không gửi audio sang Gemini. Chỉ demo mic sau khi tự thử; không TTS.

    04 / SAFE FAILURE

    Guardrails at every boundary.

    [[icon:LockClosed]]

    Access

    Verified principal, current membership, scoped SQL and RLS. UI gating is only the first layer.

    [[icon:DocumentCheck]]

    Evidence

    Documents are untrusted data. Unsupported answers are refused; invented sources are rejected.

    [[icon:ArrowPath]]

    Recovery

    Keep the write identity when the result is unknown. Reconcile before repeating conflicting writes.

    [[icon:ShieldCheck]]

    Continuity

    Errors remain visible. Independent non-AI workflows remain usable when the provider fails.
